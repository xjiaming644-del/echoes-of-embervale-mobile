## 二、键鼠 & 手柄双模操作指南

### 键盘鼠标操作
- **`W A S D` / 方向键**：移动（按住 `Shift` 冲刺）
- **`鼠标左键` / `Space`**：使用当前快捷栏工具（锄头翻地 / 水壶浇水 / 斧头伐木砍铁木桩 / 十字镐敲矿 / 猎镰剑战斗 / 竹竿钓鱼）或播种、施肥、放置机器、食用料理
- **`E` / `鼠标右键`**：与村民交谈/送礼/表白求婚、抚摸牧场动物与随行萌宠、收获作物、操作工匠机/活水鱼塘/营造奇观台/方尖传送塔
- **`1~9, 0` / `鼠标滚轮`**：切换底部 10 格快捷栏
- **`Tab`**：开启/关闭 **【伴生生态共鸣透镜】**
- **`N`**：打开 **【回响山谷 9 大区域手绘全景地图】**（查看 6 位村民实时动向与山谷完美度，支持户外与珊瑚群岛快捷传送）
- **`B` / `I`**：打开 36 格背包（支持 **`🧹 一键分类整理`** 与 **`Shift + 左键` 半数拆分**）、随身制造台、五维技能与存读档
- **`M`**：打开 **【🏆 山谷完美度 & 荣誉徽章馆 & 传闻记忆日志】**
- **`F5` / `F8`**：槽位 1 快速存档 / 读档（支持 `.tmp` 原子写入与 `.bak` 损坏自动恢复） ｜ **`F6`**：快进 1 小时
- **`F9`**：**零重启实时热重载外部美术、音效与 JSON 策划表！** ｜ **`F10`**：一键全局静音 / 恢复声音 ｜ **`F11`**：无边框全屏 / 窗口切换
